Sobre o projeto / About the project

PT

Fui convidado pela outbound.com para traduzir visualmente as principais funcionalidades da plataforma por meio deste vídeo.

A empresa utiliza inteligência artificial para escanear sites automaticamente, criar e publicar campanhas de anúncios gratuitas, entregando anúncios segmentados diretamente ao público ideal de cada negócio.

O desafio foi transformar um produto técnico em uma narrativa visual clara, dinâmica e fácil de entender, destacando o valor da automação e da tecnologia aplicada ao marketing digital.

EN

I was invited by outbound.com to visually explain the platform's core features through this video.

The company uses artificial intelligence to scan websites, automatically create, and publish free advertising campaigns that deliver targeted ads directly to each business's ideal customer.

The main challenge was translating a technical product into a clear, engaging, and easy-to-understand visual narrative, highlighting the power of automation and AI-driven marketing.

Live demo

Interactive Color Selector

EN

This is a live demo of an interactive color selector component built with React. You can test it yourself — select a color, hover over the icons to preview actions, and click to see how the animations respond dynamically to user input.

The Edit and Trash icons were animated in After Effects and exported as JSON (Lottie) files, then implemented into the interface to connect motion design with real front-end functionality.

PT

Este é um exemplo interativo de um componente de seleção de cores desenvolvido em React. Você pode testar diretamente — selecione uma cor, passe o mouse sobre os ícones para visualizar as ações e clique para ver como as animações respondem dinamicamente à interação do usuário.

Os ícones de Editar e Excluir foram animados no After Effects e exportados como arquivos JSON (Lottie), sendo depois implementados na interface para integrar motion design com funcionalidade real em front-end.
